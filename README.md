# UPI Payment Analytics & Risk Monitoring Dashboard

## 📌 Project Overview

This project presents an interactive **Power BI dashboard** designed to analyze UPI payment transactions, monitor payment performance, identify transaction failure patterns, evaluate bank performance, and analyze suspicious transaction patterns.

The dashboard uses **50,000 simulated UPI transactions** and provides business-focused insights through interactive visualizations, KPIs, filters, and DAX measures.

## 🎯 Business Objectives

* Monitor overall UPI transaction performance.
* Analyze payment success and failure rates.
* Identify major payment failure reasons.
* Compare bank-level transaction performance.
* Analyze suspicious transaction patterns using risk indicators.
* Monitor transaction processing performance.
* Provide actionable insights for payment operations and risk monitoring.

### 3. Suspicious Transaction & Risk Analysis

* Failure rate

### 5. Executive Insights & Performance Summary

## 🔍 Key Analysis Areas

The dashboard focuses on four major business areas:

**Payment Performance**
Understanding transaction volume, value, and success rates.

**Failure Monitoring**
Identifying recurring failure reasons and operational failure patterns.

**Risk Monitoring**
Highlighting unusual transaction patterns using amount, processing time, risk score, and risk level.

**Bank Performance**
Comparing banks based on transaction volume, payment success, failures, and processing performance.

## ⚠️ Disclaimer

This project is created for **portfolio and learning purposes**. The transaction dataset is simulated and does not represent real customer transactions or actual UPI payment data.

The risk analysis is intended for **suspicious transaction pattern analysis** and should not be considered an actual fraud detection system.
